Image Ingestion → HDFS
User photos are uploaded and stored in Hadoop Distributed File System across geo-redundant data nodes for fault-tolerant processing.
HDFS · Replication Factor 3
02
MapReduce Body Analysis
MediaPipe landmark coordinates are processed via MapReduce jobs — mapping body keypoints and reducing to measurement vectors across 128 nodes.
MapReduce · 128 Nodes
03
Spark ML Recommendation Engine
Apache Spark runs collaborative filtering on 50M+ fashion records, matching your body profile to patterns in historical try-on success data.
Apache Spark · MLlib
04
Real-Time Result Streaming
Kafka streams processed results back to the frontend in under 300ms, delivering personalized outfit recommendations with confidence scores.
Apache Kafka · <300ms
