📖 About This Project

This virtual try-on system combines cutting-edge AI with Hadoop Big Data processing to deliver personalized fashion recommendations. Built for beginners and professionals alike, it runs seamlessly on localhost and can be deployed anywhere.


Tech Stack: Node.js, Express, TensorFlow.js, MediaPipe, Hadoop, React/Vue
