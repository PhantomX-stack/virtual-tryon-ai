🔧 Developer API Guide

Base URL: http://localhost:5000

  • GET /api/health — Server status
  • POST /api/analyze — Body analysis & skin tone
  • POST /api/tryon — Virtual try-on overlay
  • POST /api/suggestions — Static outfit recommendations
  • POST /api/ai-suggestions — Claude AI outfit recommendations
  • POST /api/chat — Claude AI chatbot proxy
  • GET /api/hadoop/status — Live Hadoop cluster stats
  • GET /api/wardrobe — Clothing catalog

🔑 Set Anthropic API Key

To enable AI chat and personalized suggestions in standalone mode, enter your Anthropic API key. It's stored only in your browser's localStorage — never sent anywhere except directly to Anthropic.

Get your key at console.anthropic.com. Running with node server.js? Set ANTHROPIC_API_KEY in your .env instead.
